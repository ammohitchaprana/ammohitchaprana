# Media

Assets used by the profile `README.md`.

| Folder | Contents |
|---|---|
| `screenshots/` | Product screenshots (JPG, max 1600px wide) |
| `thumbs/` | Poster frames auto-extracted from the demo videos — used as clickable previews |
| `videos/` | Compressed demo recordings (H.264, 1280px wide, no audio) |

Every `thumbs/<name>.jpg` has a matching `videos/<name>.mp4`. In the README the thumbnail
links to the video — GitHub renders `.mp4` blobs with an inline player when clicked.

Source recordings were ~145 MB total; re-encoded to ~19 MB to keep the repo light.
